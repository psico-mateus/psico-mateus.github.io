# Segurança

## Versão suportada

Somente a versão atualmente publicada do site, do Guia de Emoções e da Área do paciente recebe correções de segurança.

## Como relatar uma vulnerabilidade

Não publique detalhes de uma possível vulnerabilidade em issue, discussão ou pull request. Use um dos canais privados apresentados na seção [Contato do site profissional](https://psico-mateus.github.io/#contato) e informe que se trata de um relato de segurança.

Inclua, quando possível:

- endereço e parte do sistema afetada;
- descrição objetiva do comportamento observado;
- passos mínimos para reproduzir sem usar dados reais;
- navegador e sistema operacional;
- impacto que você acredita ser possível;
- forma segura de retornar o contato.

Não inclua senha, cookie, token, código de convite ou recuperação, conteúdo de paciente ou captura com dados pessoais.

## Limites para a verificação

Ao investigar, não:

- acesse, altere ou copie dados reais;
- tente identificar pacientes;
- faça engenharia social;
- realize negação de serviço ou automação de alto volume;
- mantenha acesso depois de confirmar o problema;
- divulgue o relato antes que seja possível analisá-lo.

Este projeto não possui programa de recompensa financeira. O recebimento será confirmado pelo canal privado, sem promessa de um prazo fixo para correção.
